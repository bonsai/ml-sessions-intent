# Wants Index

Sessionごとに抽出した「やりたいこと」を、濃さ・関連・依存つきで置く場所。

## 濃さ (intensity) の目安

| 値 | 意味 |
|----|------|
| 0.9–1.0 | そのセッションの中心要求 / 繰り返し出るコア |
| 0.7–0.89 | 明確に述べられた重要テーマ |
| 0.4–0.69 | 派生・周辺 |
| 0.0–0.39 | 言及のみ / 弱いシグナル |

## ファイル

| ファイル | セッション |
|----------|------------|
| `2026-11-11-grok.yaml` | 本日 Grok セッション |

## 学習の使い方

各 want の `learning` とファイル末尾の `learning_notes` は、
次のセッション抽出時の事前知識として読む。
同じ pattern が再出現したら intensity を上げる、など。
